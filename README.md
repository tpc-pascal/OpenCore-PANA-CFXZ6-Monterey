# OpenCore-PANA-CFXZ6-Monterey

OpenCore EFI folder for Panasonic Let's Note / Toughbook CF-XZ6

---

## Device 
This EFI is **currently running** on the following hardware:

- **CPU**: Intel Core i5-7300U (Kaby Lake, 2 cores/4 threads)
- **RAM**: 8GB DDR3
- **Storage**: 256GB SSD (macOS) + 500GB HDD (data)
- **GPU**: Intel HD Graphics 620
- **WiFi & Bluetooth**: Intel Dual Band Wireless-AC 8265 Wi-Fi, Bluetooth 4.1
- **Ethernet**: Inbuilt Realtek controller (native)
